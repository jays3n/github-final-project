# Simple Interest Calculator

A simple Bash-based calculator that calculates simple interest using the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

The calculator accepts three inputs:

1. **Principal (P)** - The initial amount of money.
2. **Rate of Interest (R)** - The annual interest rate.
3. **Time Period (T)** - The time period in years.

## How to Use

Run the `simple-interest.sh` script:

```bash
./simple-interest.sh
